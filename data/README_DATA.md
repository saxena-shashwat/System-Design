# Audio Data and Test Samples

This directory isolates the raw and processed media used during the verification of the Digital Signal Processing (DSP) algorithms.

## Organization

- `raw/`: Original `.wav`, `.mp3`, and `.mp4` samples utilized as baseband sources for testing modulation and spatial processing algorithms.
- `processed/`: Rendered outputs generated by the MATLAB testbench. It features denoised versions, amplitude modulated carrier waves, and tracks with artificial reverberations.
