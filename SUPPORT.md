# Support

## Getting Help

If you have a question or need assistance with the System-Design repository, you have several options:

### 1. Check the Documentation
We maintain comprehensive README files in each subsystem directory (`src/matlab_dsp`, `src/simulink_models`, `src/esp32_firmware`). Reviewing these files often answers foundational questions about system operation.

### 2. Search Existing Issues
Before opening a new issue, please search the [Issue Tracker](https://github.com/notnamansinha/System-Design/issues) to see if someone else has already experienced the same problem.

### 3. Open a New Issue
If your problem is unique or unresolved, open a new issue. Please use the provided Issue Templates for either Bug Reports or Feature Requests, and provide as much detail as possible.

## Security Support
For reporting security vulnerabilities, please refer to our [Security Policy](SECURITY.md) instead of using the public issue tracker.
