# Security Policy

## Supported Versions

Currently, only the latest release of the System-Design repository is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| Main    | Yes                |
| < 1.0   | No                 |

## Reporting a Vulnerability

If you discover a security vulnerability within this project (such as a buffer overflow in the ESP32 firmware, or a flaw that could lead to unauthorized access on the local network setup), please do not disclose it publicly.

Instead, please report it via email or a private GitHub security advisory. We will respond as quickly as possible, usually within 48 hours, and will work with you to understand and resolve the issue.

Please include the following information in your report:
- Type of issue (e.g. buffer overflow, SQL injection, cross-site scripting, etc.)
- Full paths of source file(s) related to the manifestation of the issue
- The location of the affected source code (tag/branch/commit or direct URL)
- Any special configuration required to reproduce the issue
- Step-by-step instructions to reproduce the issue
- Proof-of-concept or exploit code (if possible)
- Impact of the issue, including how an attacker might exploit the issue

We take all security vulnerabilities seriously and will ensure that a fix is developed, tested, and pushed in a timely manner.
