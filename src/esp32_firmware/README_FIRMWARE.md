# ESP32 Flight Controller Firmware

This directory contains the embedded C++ source code formatted for **PlatformIO**.

## Development Setup

1. Install **PlatformIO IDE** (available as a VSCode extension).
2. Open this directory (`esp32_firmware`) in PlatformIO.
3. Use the `platformio.ini` environment configurations to build and flash directly to your target board (`esp32dev`).

This firmware serves as the physical testbed for the LQR models defined in the Simulink environment.
