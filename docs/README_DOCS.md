# Documentation and Research Reports

This directory serves as the definitive source for all academic reports, technical logs, and formal documentation regarding the system.

## Subdirectories

- `hardware/`: Contains raw experimental data and research on hardware behavior. Specifically, `routers.md` logs the TCP/IP latency tests, routing topologies, and subnet bridge behavior between consumer-grade routers.
- `mathematics/`: Reserved for derivations of transfer functions and system models in LaTeX/Markdown formats.
- `reports/`: Contains peer-reviewed style IEEE format PDF documents tracking weekly progress and theoretical discoveries.
